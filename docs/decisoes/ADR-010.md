# ADR-010 — Apple Maps no iOS, Google Maps no Android e capturas

**Data:** 31/10/2026 · **Status:** aceita como direção por instrução explícita no chat.

## Decisão

- iOS usa Apple Maps via MapKit/SwiftUI; Android usa Maps SDK for Android via wrapper Compose mantido por Google Maps.
- Autorizar o recorte [M5-PREVIEW-01](../engenharia/M5-PREVIEW-01.md): mapa explorável inicial, sem GPS/Pins/contas, e execução remota em simuladores para entregar capturas reais.
- Apple Maps não exige criar projeto Google. Google Maps exige projeto Google Cloud, SDK habilitado, faturamento e chave restrita por aplicativo/API. O responsável ainda não possui esse projeto; não criar conta nem habilitar faturamento automaticamente.
- Sem chave Android, exibir indisponibilidade sem montar o SDK. Não desenhar mapa fictício nem anunciar Google Maps validado.
- Upload de **PNGs de evidência solicitados**, com retenção curta no Actions, está autorizado. Continua proibida a publicação de APK/IPA, loja, release e merge automático.

## Limites

Nenhuma permissão de localização, rastreamento, geocoding, rota, persistência ou compartilhamento de dados de viagem. Câmera inicial mundial, sem representar localização pessoal. Atribuição do provedor preservada. Termos, custo, cache/offline e privacidade para uso de produção requerem revisão específica posterior.
